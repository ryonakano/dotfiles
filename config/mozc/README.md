## About
`mozc_keymap.txt` is a customized keymap file for Mozc input method editor that sets Henkan/Muhenkan keys to toggle input mode (Direct input/Hiragana).

## Installation
- Open Mozc Property dialog (`$ /usr/lib/mozc/mozc_tool --mode=config_dialog`)
- In General tab, click "Customize..." next to "Keymap style"
- In Mozc keymap editor dialog, click "Edit..."→"Import from file..."
- Select `mozc_keymap.txt` in the file chooser dialog
